# Untitled Refined

Search for the song you meant. Get it first.

Untitled Refined fixes project search on [untitled](https://untitled.stream) and adds a little polish without changing the site's design.

## What gets better

**Search**
- Exact song titles appear first, even when apostrophes, punctuation, or capitalization differ.
- Filter inside a search with `v2`, `feat`, or `#tag`. A result count shows while you search.
- The panel's **Search** tab searches every project you've opened, including your tags and notes.

**Favorites and organizing**
- Tap the heart on a track or in the player. Favorites are pinned to the top and win close search matches.
- **Play all** or **Shuffle** your favorites across projects from the panel.
- Give tracks your own **tags** and a **note** (pencil on a row, or **E**). Tags become filter buttons above the list.
- Tracks added since your last visit are marked **New**, with a filter to show only those.
- **Group versions** folds `[V1]`, `[V2]`, … into one row showing the newest version.

**Listening**
- Play counts on every track and in the player, a **Most played** sort, and a **Stats** tab with top tracks, top projects and listening time.
- Resume the last track after a reload, jump to the playing track (**.**), and a **sleep timer** (15/30/60 min or end of track).
- Compare versions (**V**) at the same spot, and loop a section with **[** and **]**.

The heart button in the bottom-left corner (**Shift+F**) opens the panel: Favorites, Recent, Search, Stats, and More (sleep timer, settings, backup). Every feature can be switched off there.

**Shortcuts** (Untitled's own Space, ←/→ and ↑/↓ still work)

| Key | Action |
| --- | --- |
| **L** | Favorite the playing track |
| **Shift+N / Shift+P** | Next / previous (in your favorites queue when it's playing) |
| **J / K**, **Enter** | Move through the list, play |
| **.** | Jump to the playing track |
| **E** | Tags and note |
| **V** | Next version at the same spot |
| **[ ] \\** | Loop start, loop end, stop looping |
| **Shift+F** | Open the panel |
| **?** | Show all shortcuts |

Everything runs locally in the page: no tracking, data collection, network requests, or extra browser permissions. Favorites, tags, notes, play counts, and settings stay in this browser’s local storage for untitled.stream.

To install, download and extract the repo, open your browser's extensions page, enable **Developer mode**, and choose **Load unpacked**.
