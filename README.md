# Untitled Refined

Search for the song you meant. Get it first.

Untitled Refined fixes project search on [untitled](https://untitled.stream) and adds a little polish without changing the site's design.

## What gets better

- Exact song titles appear first—even when apostrophes, punctuation, or capitalization differ.
- Search results slide into their new order instead of jumping around.
- The search bar opens with a quick, smooth transition.
- Press **Enter** to play the top result.
- Press **↓** from search, then use **↑ / ↓** to move through tracks.

Everything runs locally in the page: no tracking, data collection, network requests, or extra browser permissions.

To install, download and extract the repo, open your browser's extensions page, enable **Developer mode**, and choose **Load unpacked**. It works with Chrome, Brave, Edge, Opera, and Vivaldi; Firefox is not supported yet.
